# FinGaze selected-example interactive demonstration

Upload this folder's contents to a fresh repository root. Enable Settings → Pages → Deploy from a branch → main → /(root). No installation or server is required. Opening index.html locally also works.

Three 10-K natural-reading texts are selected at the nearest 25th, 50th, and 75th percentiles of word count among matched texts with two archived paths per source. The first two archived samples are retained without filtering on fixation count, duration, or model quality. Both model configurations use PhraseBank pre-training without fine-tuning. The examples are not representative performance evidence.

Only these texts and 18 paths are included. Text-local Reader labels do not identify participants or link readers across texts. All included data are downloadable or extractable even though there is no download button. Review consent and redistribution permissions for this subset before publishing. No claim is made that de-identification alone confers permission to release human data.

This page calculates selected-path TF, SR and RR and duration heatmaps in the browser; it does not reproduce the population metrics in the manuscript. It does not run a model. Inspect words using mouse or keyboard, choose paths, and play or scrub the duration timeline. Playback uses fixation durations and omits saccade times; displayed word coordinates are reflowed.

Use an account and commit identity appropriate for review anonymity. No original Git history, local paths, subject IDs, weights, or database are included. Noindex is only a request to search engines, not access control. Updating or unpublishing the site does not recall downloaded data or repository history.
